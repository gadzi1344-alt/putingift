# PutinGift — установка через GitHub

Кейс стоит 100 ⭐. Предварительное распределение: сердце 33%, кристалл 33%, шампанское 33%, NFT 1%. Все призы выдаёт администратор вручную. NFT и подарки не отправляются автоматически. Оплата изначально выключена. Баланса нет — пользователь оплачивает каждый кейс напрямую.

**Важно:** отзовите старый токен, который попал в чат, через @BotFather, и выпустите новый. Никогда не добавляйте токен и другие секреты в GitHub, не отправляйте их в чат.

## 1. Создайте базу в Cloudflare

1. Войдите на https://dash.cloudflare.com/.
2. В меню найдите **Storage & databases → D1 SQL Database**. Создайте базу `putingift-db`.
3. Откройте базу и скопируйте её **Database ID**. Таблицы вручную создавать не нужно.

## 2. Загрузите файлы в GitHub

1. На https://github.com/new создайте новый репозиторий, например `putingift`. Можно выбрать Private.
2. В репозитории нажмите **Add file → Upload files**. Распакуйте архив и загрузите файлы `index.mjs`, `wrangler.toml` и `README.md` в корень репозитория (не сам ZIP и не вложенную папку). Нажмите **Commit changes**.
3. Откройте `wrangler.toml` на GitHub и нажмите карандаш для редактирования.
4. Замените `REPLACE_WITH_D1_DATABASE_ID` на скопированный Database ID.
5. Заполните `SUPPORT_USERNAME`: точный Telegram username для выдачи и поддержки, начиная с `@`. Укажите конкретные доступные призы в `PRIZE_HEART`, `PRIZE_CRYSTAL`, `PRIZE_CHAMPAGNE`, `PRIZE_NFT`. Пример: `SUPPORT_USERNAME = "@my_username"`. Сохраните изменения через **Commit changes**.
6. Пока оставьте `PURCHASES_ENABLED = "false"`.

## 3. Подключите GitHub к Cloudflare

1. В Cloudflare перейдите в **Workers & Pages → Create application → GitHub** (или Import a repository). Разрешите доступ к GitHub и выберите свой репозиторий.
2. Имя Worker должно совпадать с `name` в `wrangler.toml`, то есть `putingift`. Поле **Build command** оставьте пустым, а в **Deploy command** укажите `npx wrangler deploy`. Root directory — корень репозитория. Нажмите **Save and Deploy**.
3. После сборки откройте созданный Worker и скопируйте его адрес `https://...workers.dev`.

## 4. Добавьте три секрета

В настройках созданного Worker найдите **Settings → Variables and Secrets** (название раздела в интерфейсе может немного отличаться). Добавьте три переменные именно типа **Secret**, затем сохраните и разверните новую версию, если панель предложит:

- `BOT_TOKEN` — новый токен бота из @BotFather.
- `WEBHOOK_SECRET` — новая случайная строка из минимум 32 латинских букв и цифр; Telegram также допускает `_` и `-`. Это не токен бота.
- `SETUP_PASSWORD` — другая случайная строка из минимум 32 латинских букв и цифр. Создайте оба секрета в менеджере паролей. Храните их в секрете, не используйте простые слова и не публикуйте в GitHub.

## 5. Подключите Telegram

1. Откройте в браузере адрес Worker и добавьте в конце `/setup`, например `https://putingift.example.workers.dev/setup`.
2. Введите **SETUP_PASSWORD** и нажмите **Подключить бота**. Страница создаст таблицы D1 и подключит webhook; токен вводить на странице не нужно.
3. После сообщения об успехе **удалите SETUP_PASSWORD** в настройках Worker и сохраните/разверните изменение. Страница настройки станет недоступна. При необходимости повторной настройки можно временно создать новый случайный SETUP_PASSWORD.
4. В Telegram откройте своего бота и отправьте `/start`. Проверьте контакт, список призов и шансы. Оплата на этом этапе выключена.

## 6. Включите продажи

Только после проверки наличия призов и возможности ручной выдачи измените в `wrangler.toml` на GitHub `PURCHASES_ENABLED = "false"` на `PURCHASES_ENABLED = "true"` и нажмите **Commit changes**. GitHub автоматически запустит новую сборку Cloudflare; дождитесь успешного развёртывания. Протестируйте весь процесс и обеспечьте поддержку.

Проверьте местные законы и правила Telegram для платных случайных призов до запуска. Заранее сообщите пользователям правила, сроки выдачи и возвратов. `/paysupport` ведёт к администратору; автоматических возвратов нет. История выигрышей хранится в D1: не удаляйте базу. `/prizes` показывает последние 20 выигрышей. Повторная доставка платежного webhook не создаёт второй выигрыш.

При изменении конфигурации помните о ранее созданных счетах: перед изменением набора призов выключите продажи и убедитесь, что старых неоплаченных счетов больше нет. Изменения в GitHub запускают новое развёртывание.
